# ScreenBoard

仿 Win11 触摸键盘的 macOS 屏幕键盘。当前做完 P0 原型和 P1 的一部分（符号页、长按备选、登录时启动），预研究见 `docs/onscreen-keyboard-research-20261029.md`。

## 功能

- 浮动键盘：点按不抢当前应用的焦点，所有桌面和全屏应用里都能用；顶部拖动条中间拖动可以移动，右端拖动可以改大小，位置会记住。
- 英文全键盘，带数字行。`⌫` 和方向键：按住并稍微滑动会连发；长按删一个词（⌥⌫）或按词移动光标（⌥←/⌥→）。
- 符号页（`&123`）：全部 ASCII 符号、数字小键盘、撤销/全选/剪切/复制/粘贴、`⌦`。都走键码，拼音下 `,` `.` `?` 等照常变成中文标点。
- 长按备选字符：长按 e、a、o、u、n、c、`.`、`'`、`-`、`[` 等键，键上方弹出备选，再点一下输入；点别处收起。备选字符用 Unicode 直接输入，ABC 和拼音下都能用。
- 按键用虚拟键码注入，系统拼音照常工作。`中/英` 键发送 ⌃空格（系统默认的“选择上一个输入法”），角标显示当前是拼音还是 ABC。
- 修饰键（⇧ ⌃ ⌥ ⌘）：点一下只作用于下一个键（半高亮），双击常锁（全高亮带横条），再点一下解除。`⇪` 只影响字母大小写。
- 菜单栏图标：显示/隐藏键盘、登录时启动、辅助功能权限状态、诊断摘要。

## 编译和安装（在 Mac 上）

```bash
scripts/build-app.sh            # 生成 build/ScreenBoard.app
scripts/build-app.sh --install  # 并复制到 /Applications、启动
```

只需要 CommandLineTools（`swiftc`），不需要 Xcode。

### 第一次运行：辅助功能权限

启动时系统会弹出提示，到“系统设置 → 隐私与安全性 → 辅助功能”里打开 ScreenBoard。没有这个权限，按键发不出去，键盘顶部会出现提示。如果授权后按键仍然没反应，退出程序再打开一次。

### 避免每次编译后重新授权（建议先做）

临时签名的程序每次重新编译都会被系统当成新程序，辅助功能列表里旧的条目对新程序无效，需要重新授权。用固定的自签名证书签名就能避免，只需建一次：

```bash
scripts/create-dev-cert.sh      # 建 "ScreenBoard Dev" 证书并导入登录钥匙串，会要登录密码
scripts/build-app.sh --install  # 自动用这个证书签名
tccutil reset Accessibility com.xstation.screenboard   # 清掉旧授权，再授权一次
```

之后重新编译不用再授权。

### 在 Linux 开发机上远程编译

`scripts/remote-build.sh [--install]` 把源码同步到测试 Mac 的 `~/screenboard` 并编译。登录信息放在项目根目录的 `.testmac.env`（`MAC_HOST=user@host`、`MAC_PASSWORD=...`），这个文件被 git 忽略。

## P0 要实测的风险

诊断日志在 `~/Library/Logs/ScreenBoard/p0.log`。菜单栏里可以看摘要，用“复制诊断摘要”可以复制出来。

| # | 风险 | 怎么测 | 看什么 |
|---|---|---|---|
| 1 | 触摸屏长按被驱动改成右键或拖动 | 手指按住一个字母键 1–2 秒；按住 `⌫` 看是否连发 | 摘要里有没有“右键按下”“其他鼠标键按下”“按键中出现拖动”；`按住时长` 能不能到 1000ms 以上 |
| 2 | 点按延迟 | 在文本编辑里用手指连续打一段字 | `送达` 的平均值和 P95；主观上是否跟手 |
| 3 | 密码框安全输入 | 在 Safari 登录页或“终端 → 安全键盘输入”下点密码框，用键盘输入 | 字符有没有进去；摘要里“安全输入时按键”的次数 |
| 4 | 辅助功能权限反复失效 | 按上面的步骤建证书，改一行代码后重新编译 | 重新编译后不重新授权，按键还能不能发出去 |

另外顺便看：

- 日志每次点按都会记 `subtype`，对比手指点和触控板点时的值，看能不能区分触摸屏和触控板（风险 6）。
- `中/英` 键能不能切换输入法：如果“系统设置 → 键盘 → 键盘快捷键 → 输入法”里关掉了 ⌃空格，这个键就没用。
- 系统拼音的候选窗会不会被键盘挡住。

测完把“复制诊断摘要”的内容和主观感受贴回来，再决定 P1 的范围。

## 实测结果（2026-10-30，VoodooI2C 触摸屏）

- **点按**：驱动在手指抬起时一次性发出左键按下和抬起，两者时间戳相同，程序拿不到按住时长。送达延迟大多在 2–7ms。
- **长按（手指不动）**：没有左键事件。达到长按时间时，驱动在手指还按着时一次性发出右键按下和抬起，所以不能按住连发。程序把右键当作“长按”处理，P1 的长按备选字符也可以在这一刻弹出。
- **按住后滑动**：驱动实时发左键按下、拖动和抬起，按住时长是真实的。连发靠这个手势。
- **`subtype`**：手指点按是 0，和普通鼠标点击一样；还没和触控板对比。
- **密码框**：安全输入开启时，合成的按键照样能输进去（风险 3 通过）。
- **备选字符**：用 `CGEventKeyboardSetUnicodeString` 发出的 `é`、`「`、`〕` 在 ABC 和拼音下都能直接输入，拼音不会拦截。
- **权限**：临时签名时，每次重新编译都要重新授权（风险 4 属实）。改用证书签名后，重新编译不再需要重新授权（已验证）。

## 代码结构

| 文件 | 内容 |
|---|---|
| `Sources/App.swift` | 入口、菜单栏、权限 |
| `Sources/KeyboardPanel.swift` | 不抢焦点的浮动窗口 |
| `Sources/KeyboardView.swift` | 按键绘制、点按、长按（右键）、拖动/改大小、连发 |
| `Sources/KeyLayout.swift` | 键位表 |
| `Sources/KeyInjector.swift` | CGEvent 注入、修饰键锁定、输入源查询 |
| `Sources/Diagnostics.swift` | P0 诊断日志和统计 |
